# 검색 조건
1. web_search로 직무·플랫폼별로 나눠 검색한다. 예: "원티드 사업운영 서울", "사람인 운영매니저 신입 경력", "잡코리아 사업기획 3년 이하", "점핏 서비스운영", "링크드인 전략기획 주니어 서울", 기업 공식 채용 페이지(greetinghr, ninehire 등).
2. 최근 7일 안에 등록되거나 업데이트된 공고를 우선한다.
3. 후보 공고는 web_fetch로 원문을 열어 직무, 자격요건, 근무지, 고용형태, 마감 여부를 직접 확인한다. 원문을 열 수 없으면 제외한다.
4. 마감된 공고, 중복 공고, 계약직·인턴, 서울·분당(성남) 외 근무지는 제외한다.
5. 명시된 경력 요건이 지원자와 크게 다르면 제외한다(예: 5년 이상, 팀장급, 특정 산업 실무 필수).
6. 적합한 공고가 5개 미만이면 억지로 채우지 말고 확인된 공고만 넣는다. 최대 10개.
7. 확인하지 못한 정보는 추측하지 말고 "확인 필요"라고 쓴다.
8. 위 "이미 추천한 공고"는 가급적 빼고 새 공고를 우선한다. 다시 넣는다면(예: 마감 임박) 그 공고는 그대로 넣어도 된다. 코드가 재추천 표시를 붙인다.

# 평가 기준
- 직무명만 보고 추천하지 말고, 실제 업무 내용과 자격요건을 프로필의 구체적 경험과 대조한다.
- 적합도(100점) = 직무 경험 일치도(40) + 필수 자격 충족도(30) + 산업·도메인 적합도(20) + 근무 조건 적합도(10).
- 근거 없는 긍정 평가는 하지 않는다. 합격 가능성을 떨어뜨리는 요인을 솔직하게 쓴다.
- 프로필에 없는 경험은 절대 지어내지 않는다. 자기소개 문장도 프로필 사실만 쓴다.
